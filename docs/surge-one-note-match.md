# Milestone 9: selectable external targets and Surge XT one-note match

![Implementation map showing ten external procedural targets, one shared eligible Surge preset cache, target-specific Top 5 retrieval, manual CMA-ES start, preserved telemetry, and the playable keyboard.](assets/milestone-9-external-target-bank.svg)

> The original bounded result below is preserved as historical evidence. The current follow-up audits the complete library with two eligibility classes and a new uncapped descriptor; see [Full-library perceptual timbre retrieval audit](perceptual-retrieval-audit.md).

## Question and boundary

Milestone 9 asks one narrow question: for a fixed external C3 reference, can Agentic Synth Twin retrieve and locally refine a real Surge XT factory preset whose rendered note becomes closer under the project's fixed transparent objective? It does not claim instrument recognition, exact reconstruction, perceptual equivalence, or behavior across pitches, velocities, chords, and phrases. Playing other notes in the preserved cockpit is exploratory audition only.

## User workflow

The cockpit presents ten discrete named references: Analog Sub Bass, FM Bell, Plucked Electric Guitar, Rhodes-style Electric Piano, Muted Synth Pluck, Analog Brass Stab, Warm Poly Pad, Sync / Hard Lead, Marimba / Mallet, and Dub Chord / Organ Stab. Selecting a target copies the exact validated WAV into a fresh target-specific run, rescores the existing eligible preset cache, shows an auditionable Top 5, chooses Base, resets telemetry, and stops at `IDLE`. Search begins only after **Start Search**.

The target selector is disabled while status is `SEARCHING`, `PAUSING`, or `PAUSED`; the API independently rejects such switches with HTTP 409. After Stop or completion, another target creates another run directory. Target, Base, Best, history, state, hashes, and audio URLs are always resolved through the active run.

The browser, objective, search telemetry, editable working copy, rendered-note cache, piano, Ableton-style computer mapping, octave/velocity controls, and optional Web MIDI input remain the same system. `clap-saw-demo` remains supported by the existing direct-search path.

## Canonical target bank

The committed `examples/targets/external-v1/` bank contains ten original deterministic procedural WAVs plus its manifest and provenance README. Each file is 2.5 seconds, scientific C3, 44.1 kHz, stereo 16-bit PCM with a two-second reference hold and half-second tail. The loader requires exact stable ordering, filenames, byte counts, SHA-256 values, format, path containment, and false `surge_used`, `third_party_samples_used`, and `preset_library_used` flags.

These targets were not generated by Surge XT and do not use third-party samples or a preset library. The UI states that provenance explicitly.

## Shared eligible-preset cache

Surge XT CLAP 1.3.4 is the first rich synth adapter. The deterministic category-round-robin selector chooses 120 factory presets before target scoring. Native states and C3 WAVs are extracted and rendered once, with six real oscillator Retrigger controls forced to their discovered value `1.0`. A preset is eligible only if it is deterministic, non-silent, unclipped, and exposes the exact authorized eight-control inventory.

Cache identity binds the plugin binary hash, ordered preset state hashes, audition contract, deterministic overrides, preset limit, and eligibility policy. Switching targets reuses those real renders and recomputes only target-dependent objective values. In the verified environment, 39 of 120 attempts were eligible; this count is evidence, not a hardcoded universal expectation.

## Objective and local search

- Audition: MIDI C3/48, velocity 100, two-second hold, half-second tail, 44.1 kHz, stereo 16-bit PCM, 64-frame blocks.
- Objective: unchanged `0.65 * spectral + 0.25 * envelope + 0.10 * loudness`.
- Active controls: exact real IDs for `A Osc 1 Shape`, `A Osc 1 Width 1`, `A Osc 1 Unison Detune`, `A Filter 1 Cutoff`, `A Filter 1 Resonance`, `A Amp EG Attack`, `A Amp EG Decay`, and `A Amp EG Release`.
- CMA-ES: seed `20260930`, population 8, 15 generations, initial sigma 0.18, normalized bounds 0..1, fixed 120-evaluation budget.
- External-target success statement: Best encountered loss does not exceed Base and the final real-Surge rerender matches the search-best WAV.
- Human success gate: owner separately judges Target/Base/Best; status remains `PENDING_OWNER_AUDITION`.

The equal-budget random control and predeclared 25% numeric gate remain part of the original hidden reachable-target regression fixture. They are intentionally not rerun after every interactive external-target search.

## Real-plugin validation

One cache identity, `ce6f61dbab39a3d12e265a8066c90a36097264eba7cc243b428e14dfd512be87`, produced a Top 5 and Base for all ten external references without rebuilding the full preset cache. Three materially different references exhausted the 120-evaluation budget:

| Target | Base loss | Best loss | Improvement | Final rerender |
| --- | ---: | ---: | ---: | --- |
| Analog Sub Bass | 0.632506 | 0.551330 | 12.83% | byte-identical |
| Plucked Electric Guitar | 0.753503 | 0.746253 | 0.96% | byte-identical |
| Rhodes-style Electric Piano | 0.519015 | 0.346361 | 33.27% | byte-identical |

The guitar result is the blunt limitation: the bounded eight-control neighborhood barely improved the proxy objective. The evidence proves the search and rerender contract, not that the result is a convincing guitar. Human listening remains pending for all three.

## Hidden reachable-target regression

The original hidden Surge target remains reproducible through `scripts/reproduce_surge_match.sh`. It retains the 120-evaluation CMA run, equal-budget random control, 25% gate, and hidden-parameter reveal. Its previously committed result reduced loss from `0.281768571357` to `0.028968679924` and matched the final rerender byte-for-byte. This controlled reachable case tests search machinery; it is not the primary user-facing target workflow.

## Known limitations

- Descriptor similarity is not human preference or instrument identity.
- A Top 5 numerical ranking may disagree with listening.
- The eight-control screen excludes otherwise valid presets whose oscillator inventory differs and cannot represent many target-defining dimensions.
- One C3 note cannot validate a playable instrument across pitch or velocity.
- The browser performs cached rendered-note audition, not low-latency native hosting.
- No arbitrary file upload, pitch detection, loudness normalization, semantic model, public hosting, additional synth, new optimizer, or LOCK is added.
