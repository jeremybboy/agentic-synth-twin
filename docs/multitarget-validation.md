# Milestone 8B: multi-target validation

Milestone 8B tests whether the direct real-synth search result from Milestone 8A survives beyond one favorable target. It runs the same frozen CMA-ES and bounded-random procedures against eight predetermined sounds generated by exact states of the real `clap-saw-demo` plugin. It also adds a blinded owner audition for Target, Starting Patch, Candidate A, and Candidate B.

## Boundary

No guitar, Rhodes, or third-party reference audio is included because the owner did not supply those recordings. Calling a saw-synth render a guitar or Rhodes would be false validation. The eight names below describe parameter regions and onset behavior; they do not assert instrument identity or broad sound-design coverage.

Filter Type remains fixed at discovered value `0`. Each target uses the same four normalized `[0,1]` dimensions from Milestone 8A: Oscillator Detuning, Unison Spread, Cutoff in Keys, and Amplitude Attack.

| Target | Fixed normalized state |
|---|---|
| Dark short onset | `[0.52, 0.15, 0.18, 0.02]` |
| Bright wide short onset | `[0.65, 0.85, 0.80, 0.03]` |
| Dark slow onset | `[0.40, 0.55, 0.22, 0.80]` |
| Bright slow onset | `[0.58, 0.35, 0.82, 0.75]` |
| Tight low-cutoff | `[0.48, 0.05, 0.12, 0.10]` |
| Wide detuned medium onset | `[0.80, 0.90, 0.62, 0.18]` |
| Muted key-like onset | `[0.38, 0.25, 0.30, 0.07]` |
| Interior cross-check | `[0.62, 0.48, 0.55, 0.42]` |

## Frozen procedure and gates

Every target is rendered twice and used only as audio by the objective. For each target, CMA-ES uses seed `20260928`, population 8, 20 generations, and 160 real-synth evaluations; bounded random search uses seed `20260929` and the same 160-evaluation budget. Reusing candidate seeds across targets makes this a paired comparison. The objective and weights are unchanged from Milestone 8A.

The predeclared gates are:

1. engine integrity passes only if all eight searches preserve exact state, deterministic rerenders, and unclipped audio;
2. optimization passes if CMA-ES improves at least 30% on at least 6/8 targets;
3. adaptive value passes only if CMA-ES beats random on at least 5/8 targets **and** has median best loss no worse than random;
4. human audition remains separate and pending until the owner completes all eight blinded comparisons.

## Result

| Target | Start | CMA best | Random best | CMA improvement | Winner |
|---|---:|---:|---:|---:|---|
| Dark short onset | 0.596372 | 0.028182 | 0.030952 | 95.27% | CMA |
| Bright wide short onset | 0.492354 | 0.290984 | 0.341664 | 40.90% | CMA |
| Dark slow onset | 0.593508 | 0.034409 | 0.033326 | 94.20% | Random |
| Bright slow onset | 0.472965 | 0.196480 | 0.278021 | 58.46% | CMA |
| Tight low-cutoff | 0.601690 | 0.012437 | 0.018427 | 97.93% | CMA |
| Wide detuned medium onset | 0.276454 | 0.158616 | 0.231016 | 42.62% | CMA |
| Muted key-like onset | 0.383283 | 0.124283 | 0.130684 | 67.57% | CMA |
| Interior cross-check | 0.206153 | 0.155838 | 0.147829 | 24.41% | Random |

Engine integrity passed, and optimization passed on 7/8 targets. CMA-ES won 6/8 individual comparisons, but median CMA best loss was `0.140060575488` versus random's lower `0.13925688528`. Therefore the exact predeclared adaptive-value gate **failed**. Total recorded search runtime was 93.601 seconds for 2,560 candidate renders, excluding target/start verification renders.

The result supports a narrower claim than “CMA works”: adaptive search helped on most selected targets, but its advantage was not robust under the complete gate. Target geometry and the fixed objective materially affect the outcome.

## Blinded audition

Run the local report after reproducing the suite:

```bash
scripts/serve_multitarget_report.sh
```

For each target, listen to Target, Candidate A, and Candidate B through to completion, then record A, B, or No Clear Difference. The backend refuses a judgment until those three playback completions are recorded, persists judgments locally, and withholds method mappings, target states, and numeric results until all eight judgments are complete. Starting Patch is audible context but not a selectable winner.

## Reproduction

```bash
scripts/reproduce_multitarget_validation.sh
```

The script rejects a non-empty output directory rather than appending to old evidence. Full WAVs, per-candidate histories, method mappings, and judgments remain under ignored `work/`. The committed compact result is [`evidence/milestone-8b/result.json`](evidence/milestone-8b/result.json).

## Next decision

Do not add new optimizers merely to rescue this gate. First complete the blinded listening test and inspect the two CMA losses plus any cases where the listener prefers the numerically worse candidate. External guitar, Rhodes, or stab recordings require a separate import contract and explicit interpretation of unattainable-target failure.
