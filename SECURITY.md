# Security policy

## Supported versions

This repository is pre-alpha research software and has no supported release yet.

## Reporting a vulnerability

Do not open a public issue for a vulnerability or accidentally exposed secret. Use GitHub's private vulnerability reporting for this repository when available; otherwise contact the repository owner privately through their GitHub profile.

Include the affected revision, reproduction steps, expected impact, and any proposed mitigation. Do not include real credentials or private audio/data in a report.
